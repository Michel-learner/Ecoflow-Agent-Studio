# EcoFlow 跨市场营销 Agent · 跨境新创队

> 飞书 AI 先锋未来人才大赛 · 2026 · EcoFlow 企业命题参赛作品

基于飞书 Aily 编排四个营销 Agent（证据检索 / 内容生成 / 内容审核 / 效果追溯），将产品资料、市场事件、UGC 与历史投放数据连接为一条 **证据驱动、可追溯、可复用的营销内容闭环**，支撑 EcoFlow 北美、欧洲、日本等市场在 Instagram、KOL 和独立站渠道的内容生产、审核与效果反向沉淀。

## 关于本仓库

**`index.html` 为方案原型展示页**，用于直观呈现方案架构、工作流、各 Agent 运行范例与飞书产品集成方式。

## 方案亮点

- **证据驱动内容生成**：Agent A 将分散的市场信息整理为结构化 Evidence，Agent B 只基于可用证据生成本地化内容
- **全链路可追溯**：每条 Claim 可追溯到对应 evidence_id，投放表现可反向回溯到原始市场洞察
- **独立审核与定向返工**：Agent C 不通过时精准返回对应环节（证据问题回 A，文案问题回 B），降低整条流程重复成本
- **效果反向沉淀资产**：Agent D 从高表现内容提炼资产卡，反馈给下一轮内容生成，越用越聪明
- **飞书原生底座**：飞书 Aily 做调度引擎、多维表格做数据底座、自动化驱动流转、审批做人工闸门
